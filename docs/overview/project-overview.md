# 프로젝트 개요

## 앱 이름

- 일/주간 미션창

## 앱의 역할

- 사용자가 일일, 주간으로 해야 할 일을 미션 창 형식으로 보여주어 접근성과 편리함을 제공한다.

## 주요 기능

- 미션 추가
- 미션 보기
- 미션 삭제
- 미션 완료사항 체크
- 미션 기록 보기

## 화면 설명

### 메인 화면

- 사용자의 미션을 전반적으로 확인 가능한 화면이다.
- 각 박스는 하나의 미션을 의미한다.
- 미션 박스를 마우스 좌클릭으로 길게 눌러 미션 완료 상태로 갱신할 수 있다.
- 미션 추가, 미션 역사 보기, 삭제 등의 아이콘을 가진다.

### 미션 추가 화면

- 미션을 추가하기 위한 화면이다.
- 일일 미션과 주간 미션을 나누어 등록한다.
- 미션 내용, 기간, 횟수 등을 입력한다.
- 주간 미션일 경우 요일을 체크한다.
- 등록 버튼을 누르면 미션이 추가된다.

### 미션 역사 보기 화면

- 여태까지 등록했었던 미션들을 확인하는 화면이다.
- 미션 목록을 가진다.
- 미션 목록의 한 요소를 클릭하면 해당 미션을 어떻게 완료했는지 달력 형태로 표현한다.

## 완료사항 체크

- 현재 있는 미션을 마우스 좌클릭으로 길게 눌러 완료사항을 체크한다.
- 기본적으로 횟수가 한 번이면 오른쪽 빈 동그라미 안에 체크 표시가 생긴다.
- 여러 번 수행해야 하는 미션일 경우 맨 앞 막대부터 하나씩 채워진다.

## 미션 추가 및 삭제

- 메인 화면에서 이미 등록한 미션을 삭제할 수 있다.
- 삭제 버튼을 누른 뒤 삭제하기 원하는 미션을 클릭한다.

## 미션 리스트 확인

> 아직 추가되지 않은 기능이다.

- 여태까지 등록한 미션을 확인할 수 있다.
- 미션 목록이 존재한다.
- 미션 목록의 항목을 클릭하면 이전 날짜들을 보여주는 달력 형태의 마일스톤이 등장한다.
- 마일스톤에서 미션 완료 여부를 확인할 수 있다.
- 횟수 미션일 경우 부분 완료와 완전 완료의 색상 차이가 존재한다.
- 미션 리스트에서도 미션 삭제와 수정이 필요할 수 있다.

# 유스케이스 명세서

이 문서는 Daily Weekly Mission 앱의 기능 흐름을 구현하기 위해 작성한 유스케이스 명세서입니다. 각 기능은 사용자 관점의 목적, 입력값, 기본 흐름, 예외 상황을 기준으로 정리합니다.

## 1. 미션 확인

| 항목 | 내용 |
|---|---|
| 기능명 | 미션 확인 |
| 사용자 | 일반 사용자 |
| 목적 | 사용자가 메인 화면에서 등록된 일일/주간 미션과 현재 진행 상태를 확인한다. |
| 입력값 | 없음. 앱 실행 또는 메인 화면 진입을 통해 확인한다. |

### 기본 흐름

1. 사용자가 앱을 실행하거나 메인 화면으로 이동한다.
2. 시스템은 저장된 미션 목록을 불러온다.
3. 시스템은 미션을 일일 미션과 주간 미션으로 구분하여 표시한다.
4. 시스템은 각 미션의 제목, 내용, 목표 횟수, 현재 진행 횟수, 완료 상태를 표시한다.
5. 사용자는 메인 화면에서 현재 수행해야 할 미션과 진행 상황을 확인한다.

### 예외 흐름

- 등록된 미션이 없으면 시스템은 `아직 미션이 없습니다.` 또는 빈 목록 상태를 표시한다.
- 저장된 미션 데이터를 불러오지 못하면 시스템은 오류 메시지를 표시한다.

### 결과

- 사용자는 현재 등록된 미션 목록과 진행 상태를 확인할 수 있다.

## 2. 미션 추가

| 항목 | 내용 |
|---|---|
| 기능명 | 미션 추가 |
| 사용자 | 일반 사용자 |
| 목적 | 사용자가 원하는 형태의 미션을 추가한다. |
| 입력값 | 제목, 내용, 기간, 횟수, 일간 또는 주간, 주간 요일 선택(주간 선택 시) |

### 기본 흐름

1. 사용자가 메인 화면에서 주간 미션 또는 일간 미션 옆의 `+` 버튼을 클릭한다.
2. 시스템은 미션 추가 창을 생성한다.
3. 사용자는 제목, 내용, 기간, 횟수, 미션 유형을 입력한다.
4. 주간 미션을 선택한 경우 사용자는 수행할 요일을 선택한다.
5. 사용자가 추가 버튼을 누른다.
6. 시스템은 입력값을 검증한다.
7. 입력값이 올바르면 시스템은 미션을 저장한다.
8. 메인 화면에 새 미션이 추가된다.

### 예외 흐름

- 제목이 비어 있으면 시스템은 저장하지 않고 안내 메시지를 표시한다.
- 횟수 항목이 비어 있으면 시스템은 저장하지 않고 안내 메시지를 표시한다.
- 주간 미션 선택 시 요일이 선택되지 않은 경우 저장하지 않고 안내 메시지를 표시할 수 있다.

### 결과

- 새 미션이 일일 또는 주간 미션 목록에 추가된다.

## 3. 미션 삭제

| 항목 | 내용 |
|---|---|
| 기능명 | 미션 삭제 |
| 사용자 | 일반 사용자 |
| 목적 | 사용자가 원하는 미션을 삭제한다. |
| 입력값 | 없음. 단, 삭제할 미션을 클릭한다. |

### 기본 흐름

1. 사용자가 메인 화면에서 팝업 창의 삭제 버튼을 클릭한다.
2. 시스템은 삭제 모드로 전환된다.
3. 사용자는 삭제하기 원하는 미션을 클릭한다.
4. 시스템은 선택된 미션을 삭제 처리한다.
5. 메인 화면에서 해당 미션이 사라진다.

### 예외 흐름

- 메인 화면에 미션이 없으면 시스템은 `미션이 없습니다.` 메시지를 출력한다.
- 사용자가 미션 외 다른 영역을 클릭하면 시스템은 삭제 모드를 해제한다.

### 결과

- 선택한 미션이 메인 화면의 미션 목록에서 제거된다.

## 4. 미션 완료 사항 체크

| 항목 | 내용 |
|---|---|
| 기능명 | 미션 완료 사항 체크 |
| 사용자 | 일반 사용자 |
| 목적 | 미션의 진행 상황을 체크하여 갱신한다. |
| 입력값 | 없음. 사용자의 마우스 클릭 동작을 사용한다. |

### 기본 흐름

1. 사용자가 메인 화면에서 현재 완료한 미션을 길게 좌클릭한다.
2. 시스템은 해당 미션의 진행 상황을 갱신한다.
3. 미션 진행 횟수를 충족하지 않은 경우, 시스템은 진행 상황만 갱신한다.
4. 진행 상황 갱신 시 막대바 진척도와 완료 횟수 표시가 증가한다.
5. 미션 진행 횟수를 충족한 경우, 시스템은 해당 미션을 완전히 완료 처리한다.
6. 완료 처리된 미션은 맨 오른쪽 전체 완료 동그라미에 체크 표시가 생긴다.
7. 완료 처리된 미션은 현재 기간 동안 비활성화된다.
8. 일일 또는 주간 기간이 지나면 시스템은 각 미션의 진행 횟수를 초기화한다.

### 예외 흐름

- 사용자가 진행 상황을 잘못 클릭한 경우를 대비해 현재 진행 상황을 취소하는 기능이 필요하다.

### 결과

- 미션의 진행 횟수와 완료 상태가 갱신된다.
- 목표 횟수를 충족한 미션은 완료 상태로 표시된다.

## 5. 미션 기록 보기

| 항목 | 내용 |
|---|---|
| 기능명 | 미션 기록 보기 |
| 사용자 | 일반 사용자 |
| 목적 | 사용자의 지난 미션 기록을 확인한다. |
| 입력값 | 없음. 미션 기록 버튼 클릭을 사용한다. |

### 기본 흐름

1. 사용자가 메인 화면에서 미션 기록 버튼을 클릭한다.
2. 시스템은 미션 기록 창을 생성한다.
3. 시스템은 기록 확인이 가능한 미션 리스트를 표시한다.
4. 사용자는 미션 리스트 중 기록을 보고 싶은 미션을 클릭한다.
5. 시스템은 선택한 미션의 기록을 달력 형태로 표시한다.

### 예외 흐름

- 미션이 없을 경우 시스템은 `아직 미션이 없습니다.` 메시지를 출력한다.
- 기록된 미션의 개수는 현재 20개로 제한한다.

### 결과

- 사용자는 선택한 미션의 지난 완료 기록을 달력형 화면에서 확인할 수 있다.

## 구현 시 참고 사항

- 미션 확인은 앱 실행 또는 메인 화면 진입 시 기본적으로 수행되는 조회 흐름이다.
- 미션 추가 기능은 `일일 미션 추가`와 `주간 미션 추가` 버튼에서 같은 추가 창 또는 같은 저장 흐름을 공유할 수 있다.
- 미션 삭제는 사용자가 실수로 삭제하지 않도록 삭제 모드 진입과 미션 선택 단계를 분리한다.
- 미션 완료 체크는 기간 단위가 중요하므로 일일 미션은 날짜 기준, 주간 미션은 주 시작일 기준으로 완료 기록을 관리한다.
- 미션 기록 보기는 저장된 완료 기록을 기반으로 화면 표시용 데이터를 계산한다.
